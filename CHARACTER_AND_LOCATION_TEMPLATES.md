# Character & Location Asset Templates

**Status:** work in progress
**Last updated:** 2026-07-29

This file tracks the asset pipeline for every character portrait and location
background in the game. Each entry records the current provenance of the
portrait image, the written profile (bio / relationship text), and the
character's events. The long-term goal — stated at the bottom — is to move
every entry to a fully custom state.

---

## Long-term goal

The aspiration for this project is that every character template reaches the
following state:

| Field       | Target                                                          |
| ----------- | --------------------------------------------------------------- |
| **Sex**     | Known (Male / Female / Other) — no entries remain "unknown"     |
| **Image**   | **Custom** — hand-painted or commissioned art, not AI-generated |
| **Profile** | **Custom** — written by a human author, not AI-generated        |
| **Events**  | **Custom** — authored dialogue and scenarios, not AI-generated  |

The same aspiration applies to locations: every location should reach custom
image, custom description, and a verified location reference.

Progress can be tracked by counting entries that still read "AI-generated" or
"unknown" in each column.
