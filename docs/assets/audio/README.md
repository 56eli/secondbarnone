# Audio assets

`warm-piano-loop.wav` is a small mono 11.025 kHz / 8-bit PCM loop generated for this project as copyright-free background music. It is intentionally compact (about 130 KB) so it stays inside the deployed asset budget.

The track is dedicated to the public domain/CC0 for project use. Browser autoplay rules are respected: music only starts after player interaction and a non-zero Settings volume.
